# 📱 ইলেকট্রনিক্স ইম্পোর্টার্স হোলসেল বিডি (Electronics Importers Wholesale BD)
> সরাসরি চায়না থেকে ইমপোর্টকৃত ট্রেন্ডিং স্মার্ট গ্যাজেট, ব্লুটুথ নেকব্যান্ড, হেডফোন ও কারাওকে স্পিকারের প্রিমিয়াম ই-কমার্স প্ল্যাটফর্ম।

---

## 🌟 মূল ফিচারসমূহ (Key Features)
1. **ডুয়েল প্রাইসিং সিস্টেম (খুচরা + পাইকারি রেট):** প্রতিটি পণ্যে সাধারণ খুচরা মূল্যের পাশাপাশি ১০+ পিসে পাইকারি ডিলার রেট স্বয়ংক্রিয়ভাবে কার্যকর হয়।
2. **স্মার্ট ১-ক্লিক হোয়াটসঅ্যাপ অর্ডার:** কাস্টমার কার্টে নাম, ফোন নম্বর ও ডেলিভারি ঠিকানা দিলে তাৎক্ষণিক সুন্দর মেমো তৈরি হয়ে বড় ভাইয়ের হোয়াটসঅ্যাপে চলে যায়।
3. **রেফারেন্স সাইট (`electrohubbd24.com`) থেকে উন্নত ডিজাইন:**
   - ছবির হাই-রেজ্যুলেশন গ্যালারি ও কালার ভ্যারিয়েন্ট সিলেক্টর
   - ক্যাটাগরি ফিল্টার চিপস ও লাইভ প্রোডাক্ট সার্চ বার
   - মূল ফিচার ও বিস্তারিত স্পেসিফিকেশন টেবিল
   - সংশ্লিষ্ট ট্রেন্ডিং প্রোডাক্টস (Related Products)
4. **১০০% ফ্রি হোস্টিং ফ্রেন্ডলি:** Vercel Edge CDN-এ লাইফটাইম ফ্রিতে কোনো সার্ভার চার্জ ছাড়া চলবে।
5. **গুগল কোর ওয়েব ভাইটালস (Core Web Vitals):** সুপারফাস্ট লোডিং (LCP < 1.0s) ও নিখুঁত মোবাইল ফ্রেন্ডলি।

## 🚀 কীভাবে লোকাল কম্পিউটারে রান করবেন (How to Run Locally)

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল (অলরেডি করা আছে)
npm install

# ২. ডেভেলপমেন্ট সার্ভার চালু
npm run dev
```
এরপর ব্রাউজারে `http://localhost:3000` ওপেন করলেই সম্পূর্ণ ওয়েবসাইট দেখা যাবে।

## 🌐 Vercel-এ ১০০% ফ্রিতে লাইভ করার সহজ নিয়ম (How to Deploy to Vercel)

1. প্রজেক্টটি গিটহাবে (`GitHub`) একটি নতুন রিপোজিটোরিতে পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial release of Electronics Importers Wholesale BD"
   git branch -M main
   git remote add origin <YOUR_GITHUB_REPO_URL>
   git push -u origin main
   ```
2. [vercel.com](https://vercel.com)-এ যান এবং GitHub অ্যাকাউন্ট দিয়ে লগইন করুন।
3. "Add New Project" এ ক্লিক করে এই রিপোজিটোরিটি সিলেক্ট করুন এবং **Deploy** বাটনে চাপ দিন।
4. ১ মিনিটের মধ্যে Vercel আপনাকে একটি ফ্রি লাইভ ডোমেইন লিংক (যেমন: `electronics-bd.vercel.app`) দিয়ে দেবে!
